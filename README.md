# Geographic Data Dumps

## 1. Repository Overview

This directory contains ready-to-use geographic data dumps: countries, regions, cities, currencies, languages, and multilingual alternative names. The package is provided in SQL, CSV, and JSON formats for direct loading into databases or use in ETL and analytics workflows.

## 2. Directory Structure

| Path | Purpose |
| --- | --- |
| `output/sql/` | SQL exports for database imports. |
| `output/csv/` | CSV exports grouped by entity and country partitions where applicable. |
| `output/json/` | JSON exports grouped by entity and country partitions where applicable. |
| `output/README.md` | This summary document for data consumers. |
| `output/DATA_LICENSE.md` | Combined licensing notes for upstream data sources. |
| `output/ATTRIBUTION.md` | Attribution text and source links for reuse. |

Each entity is available in multiple formats so consumers can choose between database import (`sql`), tabular processing (`csv`), or application integration (`json`).

### 2.1 File Layout by Entity

| Entity Folder | Pattern | Notes |
| --- | --- | --- |
| `countries` | `part_001.*` + `altname/part_001.*` | Global file + language alt-names file. |
| `currencies` | `part_001.*` + `altname/part_001.*` | Global file + language alt-names file. |
| `languages` | `part_001.*` + `altname/part_001.*` | Global file + language alt-names file. |
| `regions` | `<COUNTRY>/part_001.*` + `<COUNTRY>/altname/part_001.*` | Partitioned by country code. |
| `cities` | `<COUNTRY>/part_001.*` + `<COUNTRY>/altname/part_001.*` | Partitioned by country code. |

### 2.2 Country Partitions

For `cities` and `regions`, data is split by ISO-like country folders (for example `AD`, `AE`, `US`, `DE`) to keep files smaller and easier to process incrementally.
