# Attribution

If your project uses this data package, include attribution to the original sources below.

## Recommended Attribution Text

"Contains geographic data derived from OpenStreetMap, GeoNames, Wikidata, Who's On First, Unicode CLDR, UNData, and CityPopulation."

## Source Links

- OpenStreetMap: https://www.openstreetmap.org/
- GeoNames: https://www.geonames.org/
- Wikidata: https://www.wikidata.org/
- Who's On First: https://whosonfirst.org/
- Unicode CLDR: https://cldr.unicode.org/
- UNData / UNSD: https://data.un.org/
- CityPopulation: https://www.citypopulation.de/

## Notes

- OpenStreetMap attribution is mandatory for OSM-derived data.
- Some downstream use cases may require additional notices depending on how data is redistributed.
